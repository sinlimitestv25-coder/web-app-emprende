# Entrega Nexo v0.3

## Parte 1 de 2

Contiene el código fuente de la v0.3, el panel funcional del emprendimiento, datos de demostración persistentes, gestión de productos, stock, clientes, proveedores, pedidos, portal, carrito, pruebas y la base de seguridad multitenant preparada en la v0.2.

Commit sugerido:

`Nexo v0.3 (1/2): panel funcional del emprendimiento y gestión de pedidos`

## Parte 2 de 2

Contiene la compilación estática completa en `dist`, lista para que Netlify publique la versión 0.3.

Commit sugerido:

`Nexo v0.3 (2/2): portal de ventas y compilación para Netlify`

## Orden de subida

1. Descomprimir y subir primero el contenido de la parte 1.
2. Confirmar la primera subida con su commit sugerido.
3. Descomprimir y subir después el contenido de la parte 2.
4. Confirmar la segunda subida con su commit sugerido.

Los archivos ZIP no se suben al repositorio. Cada parte contiene menos de 100 archivos y conserva la estructura de carpetas.

## Alcance de los datos

Esta versión utiliza datos de prueba guardados localmente en el navegador. No requiere ejecutar SQL nuevo y no carga productos, clientes, proveedores ni pedidos en Supabase.
